# Атаки
---

* #  Первая фаза
	*  *Движения напоминают танцевальные, плавные, а атаки резкие*
	*  *С неё постепенно рвется одежда, обнажая боевые импланты*
	*  Вдохновение - cuphead, пикок и мисс форчун из skullgirls
	
	* ###  Ближний бой
		*  Короткие 2 удара ногами  ( [[beat-em-up#^6ca5fd| * ]] )
		*  Колесо
			*  *Делает колесо в сторону Шерон*
			
		*  Подсечка  ( [[beat-em-up#^9f5072| % ]] )
			*  *Падает на шпагат и поворачивается примерно на 200 градусов, сбивая Шерон с ног при попадании*
			
		*  Комбо кием
			1.  *Горизонтальный удар*  ( [[beat-em-up#^6ca5fd| * ]] )
			2.  *Резкий удар противоположной стороной*  ( [[beat-em-up#^6ca5fd| * ]] )
			3.  *Удар ногой*  ( [[beat-em-up#^6ca5fd| * ]] )
			4.  *Сечение сверху вниз*  ( [[beat-em-up#^6ca5fd| * ]] )
			
		 
	* ###  Дальний бой
		*  Стреляет очередью из пулек из пальцев
			*  *Снаряд летит сначала медленно, потом ускоряется*
		 
	* ###  Специальные
		*  Поломка
			*  *Выполняет эту атаку при переходе с первой фазы на вторую*
			*  *Начинает бесконтрольно дергаться и стрелять горячим паром во все стороны*
			
		
	
* #  Вторая фаза
	*  *Нужно чтобы Шерон нанесла достаточно урона*
	*  *Двигается машинально и резко, не делает шаги - подлетает на пару*
	*  *Вдохновение - пейнвилл из skullgirls*
	
	* ###  Ближний бой
		*  Таран  ( [[beat-em-up#^a2c027| ! ]] )
			*  *Летит всем телом в сторону Шерон*
		*  Одиночный удар рукой
		*  Хлестание хвостом
			*  *поворачивается всем телом чтобы ударить*
		
	* ###  Дальний бой
		*  Выстрел паром
			*  *Выпускает несколько горячих потоков пара вокруг себя*
		 
	* ###  Специальные
		*  Швыряет ближайшую крысу в Шерон
		 
	


# Описание
---
>  
 >  Дочь дона, крыса-киборг оснащенная боевыми имплантами. Ей нравится заниматься танцами и она владеет ночным клубом. Помогает отцу, но имеет и личные дела.
>
